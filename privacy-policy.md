Privacy Policy – Rack Scorer
Effective date: February 25, 2026

Rack Scorer (“we”, “us”, “our”) provides a Boone & Crockett elk scoring app. This Privacy Policy explains how Rack Scorer handles user data.

1. Developer and Contact
Developer: Elevation Technology Solutions
Contact email: elevationtechnology@outlook.com

2. Data We Access and Collect
Rack Scorer processes the following data entered by the user:

Hunt details (for example: hunter name, date, unit)
Elk scoring measurements and scoring results
Saved score summaries generated by the user
This data is provided directly by the user in the app.

3. How Data Is Used
We use this data only to:

Calculate elk scores
Display score summaries
Save score records on the user’s device
Export a summary image when the user requests it
4. Data Sharing
We do not sell user data.
We do not share user data with advertisers or data brokers.
We do not transmit user-entered scoring data to our servers.

If the user chooses to save/export an image, Android/Windows may store that file using the device operating system file APIs.

5. Data Storage and Security
User-entered scoring data is stored locally on the user’s device.
We do not operate a remote backend for this data.
We apply reasonable technical measures appropriate for a local-device app design.
6. Data Retention and Deletion
Data remains on device until the user deletes it (for example, removing saved scores) or uninstalls the app.
Exported images remain in the save location chosen by the app/user until deleted by the user.
If you need support with deletion questions, contact us at [support email].
7. Permissions
Rack Scorer only requests/accesses permissions needed for app features (for example, saving summary images to device storage where applicable).

8. Children
Rack Scorer is not directed to children under 13.

9. Changes to This Policy
We may update this Privacy Policy from time to time. Updates will be posted at this same URL with a revised Effective date.
